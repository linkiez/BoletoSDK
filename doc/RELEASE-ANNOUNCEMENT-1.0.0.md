# GitHub Release Announcement - v1.0.0

Release date: 2026-05-09

## Long Form Announcement

BoletoSDK v1.0.0 is now publicly available.

This first stable release delivers complete CNAB400 and CNAB240 support, including parsing, generation, validation, and schema coverage.

Highlights:

- Full CNAB400 support with remittance and return flows
- Full CNAB240 support for file and batch structures with segments P, Q, and R
- Boleto document generation in HTML and PDF
- Barcode generation (I2of5) and PIX QR code support
- PIX payload-only support for HTML and PDF rendering
- Stream-based PDF generation with improved error propagation
- Email utilities for boleto delivery with PDF/HTML attachments

Quality snapshot:

- 905 tests passing
- 95.69% statement coverage
- Cross-format integration validated (CNAB240 and CNAB400)
- npm package published as @linkiez/boleto-sdk@1.0.0

Useful links:

Thank you to everyone who contributed with testing, feedback, and implementation reviews.
