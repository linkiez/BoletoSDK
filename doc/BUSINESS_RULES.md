## 1. Nosso Número (Our Number)

### Definition

Nosso Número is a unique identifier for each boleto within a beneficiary's account. It's used to track and reconcile payments.

### General Rules

| Rule | Description |
|------|-------------|
| **Uniqueness** | Must be unique per beneficiary account |
| **Generation** | Can be generated by beneficiary or bank |
| **Format** | Bank-specific (varies by bank and carteira) |
| **Check Digit** | Most banks require calculated check digit |
| **Padding** | Left-padded with zeros to required length |

## 2. Check Digit Algorithms

### Modulo 10 (Standard)

Used by several banks for barcode and line validation.

```typescript
function modulo10(sequence: string): number {
  let sum = 0;
  let weight = 2;

  for (let i = sequence.length - 1; i >= 0; i--) {
    const digit = parseInt(sequence[i]);
    let product = digit * weight;

    // If product > 9, sum digits (e.g., 14 → 1+4=5)
    if (product > 9) {
      product = Math.floor(product / 10) + (product % 10);
    }

    sum += product;
    weight = weight === 2 ? 1 : 2;
  }

  const remainder = sum % 10;
  return remainder === 0 ? 0 : 10 - remainder;
}
```

### Modulo 10 Itaú

Special variant for Itaú bank.

```typescript
function modulo10Itau(sequence: string): string {
  let sum = 0;
  let weight = 2;

  for (let i = sequence.length - 1; i >= 0; i--) {
    const digit = parseInt(sequence[i]);
    let digitProduct = digit * weight;

    // Sum individual digits of product
    if (digitProduct > 9) {
      digitProduct = Math.floor(digitProduct / 10) + (digitProduct % 10);
    }

    sum += digitProduct;
    weight = weight === 2 ? 1 : 2;
  }

  const remainder = sum % 10;
  return remainder === 0 ? '0' : (10 - remainder).toString();
}
```

### Modulo 11 (Standard)

```typescript
function modulo11(sequence: string, weightMax: number = 9): string {
  let sum = 0;
  let weight = 2;

  for (let i = sequence.length - 1; i >= 0; i--) {
    sum += parseInt(sequence[i]) * weight;
    weight = weight === weightMax ? 2 : weight + 1;
  }

  const remainder = sum % 11;

  // Common rule: remainder 0 or 1 → DV = 0
  if (remainder <= 1) {
    return '0';
  }
  return (11 - remainder).toString();
}
```

### Modulo 11 Bradesco

```typescript
function modulo11Bradesco(sequence: string): string {

```

### Modulo 11 Sicredi

```typescript
function modulo11Sicredi(sequence: string): number {
  let sum = 0;
  let weight = 2;
  const base = 9;

  for (let i = sequence.length - 1; i >= 0; i--) {
    sum += parseInt(sequence[i]) * weight;
    weight = weight < base ? weight + 1 : 2;
  }

  let dv = 11 - (sum % 11);

  // If DV > 9, set to 0
  if (dv > 9) {
    dv = 0;
  }

  return dv;
}
```

### DV Sicoob

Uses fixed weight pattern.

```typescript
function dvSicoob(sequence: string): string {
  // 21-character sequence
  const fixedWeights = '319731973197319731973';
  let sum = 0;

  for (let i = 0; i < 21; i++) {
    sum += parseInt(sequence[i]) * parseInt(fixedWeights[i]);
  }

  const remainder = sum % 11;

  if (remainder <= 1) {
    return '0';
  }
  return (11 - remainder).toString();
}
```

### Modulo 10 + 11 Banrisul (Double DV)

Special algorithm using two sequential calculations.

```typescript
function dvBanrisul(sequence: string): string {
  // Step 1: Calculate first DV using modulo 10
  let dv1 = modulo10Banrisul(sequence);

  // Step 2: Calculate second DV using modulo 11
  let dv2 = modulo11Banrisul(sequence, dv1);

  return dv1.toString() + dv2.toString();
}

function modulo10Banrisul(sequence: string): number {
  let sum = 0;
  let weight = 2;

  for (let i = sequence.length - 1; i >= 0; i--) {
    const digit = parseInt(sequence[i]);
    const result = digit * weight > 9 ? (digit * weight) - 9 : digit * weight;
    sum += result;
    weight = weight === 2 ? 1 : 2;
  }

  const remainder = sum < 10 ? sum : sum % 10;
  return remainder === 0 ? 0 : 10 - remainder;
}

function modulo11Banrisul(sequence: string, dv1: number): number {
  sequence = sequence + dv1.toString();

  let sum = 0;
  let weight = 2;
  const base = 7;

  for (let i = sequence.length - 1; i >= 0; i--) {
    sum += parseInt(sequence[i]) * weight;
    weight = weight < base ? weight + 1 : 2;
  }

  const remainder = sum < 11 ? sum : sum % 11;

  // If remainder = 1, DV is invalid → increment DV1 and recalculate
  if (remainder === 1) {
    const newDV1 = dv1 === 9 ? 0 : dv1 + 1;
    return modulo11Banrisul(sequence.slice(0, -1), newDV1);
  }

  return remainder === 0 ? 0 : 11 - remainder;
}
```

## 3. Barcode and Digitável Line

### Barcode Structure (47 digits)

```
BBBMC.CCCCVVVVVVVVVVVVVVVVVVVVVVVVVVVVVVVVVVVV
```

Where:

- **BBB** (3): Bank code
- **M** (1): Currency code (always '9' for Real)
- **C.CCCC** (5): Free field part 1
- **VVVVV...** (25): Free field parts 2-5
- **DV** (1): Check digit (position 4 in formatted)

### Free Field (Campo Livre) - 25 digits

Bank-specific format. Examples:

**Itaú (Carteira 112)**:

```
{carteira}{nossoNumero}{dv}{agencia}{conta}{digitoConta}000
```

**Bradesco (Carteira 09)**:

```
{agencia}{carteira}{nossoNumero}{conta}{digitoConta}
```

**Santander (Carteira 101)**:

```
9{codigoCedente}{nossoNumero}{dv}0101
```

**Sicredi (Carteira 1/A)**:

```
{carteira}1{nossoNumero}{agencia}{posto}{codigoCedente}10{dv}
```

### Barcode Check Digit Calculation

```typescript
function calculateBarcodeDV(barcode: string): string {
  // Remove position 4 (DV position)
  const sequence = barcode.substring(0, 4) + barcode.substring(5);

  return modulo11Barcode(sequence);
}

function modulo11Barcode(sequence: string): string {
  let sum = 0;
  let weight = 2;

  for (let i = sequence.length - 1; i >= 0; i--) {
    sum += parseInt(sequence[i]) * weight;
    weight = weight === 9 ? 2 : weight + 1;
  }

  const remainder = sum % 11;

  // Special barcode rule
  if (remainder === 0 || remainder === 1 || remainder === 10) {
    return '1';
  }
  return (11 - remainder).toString();
}
```

### Digitável Line (Linha Digitável) - 47 digits formatted

Format: `AAAAA.BBBBB CCCCC.DDDDDD EEEEE.FFFFFF G HHHHHHHHHHHHHH`

Where:

- **AAAAA.BBBBB**: Field 1 (Bank code + currency + free field part 1 + DV)
- **CCCCC.DDDDDD**: Field 2 (Free field part 2 + DV)
- **EEEEE.FFFFFF**: Field 3 (Free field part 3 + DV)
- **G**: General check digit (from barcode)
- **HHHHHHHHHHHHHH**: Due date factor + amount

**Field DVs** calculated using Modulo 10.

## 4. Date Validations

### Due Date (Data de Vencimento)

**Fator de Vencimento** (Due Date Factor):

```typescript
function fatorVencimento(dueDate: Date): number {
  const baseDate = new Date(1997, 9, 7); // October 7, 1997
  const today = new Date();

  // Calculate range
  const rangeFromToday = Math.floor((dueDate.getTime() - today.getTime()) / (1000 * 60 * 60 * 24));

  // FEBRABAN rule: acceptable range
  if (rangeFromToday > 5500 || rangeFromToday < -3000) {
    throw new Error(`Due date outside acceptable range (±8/15 years from today). FEBRABAN 082/2012`);
  }

  // Calculate factor (cycles when reaching 9999)
  let factor = Math.floor((dueDate.getTime() - baseDate.getTime()) / (1000 * 60 * 60 * 24));

  // Cycle when reaching 9999 (February 21, 2025)
  while (dueDate > addDays(baseDate, 9999)) {
    baseDate = addDays(dueDate, -(factor - 9999 - 1 + 1000));
  }

  return factor;
}
```

**Rules**:

```typescript
// Due date validations
const rules = {
  past: {
    maxDaysAgo: 3000, // ~8 years
    message: 'Due date too far in the past'
  },
  future: {
    maxDaysAhead: 5500, // ~15 years
    message: 'Due date too far in the future'
  },
  factorCycle: {
    maxFactor: 9999,
    resetDate: '2025-02-21', // Factor resets to 1000
    message: 'Factor cycles after reaching 9999'
  }
};
```

## Validation Workflow

### Complete Validation Sequence

```typescript
function validateBoleto(boleto: Boleto): void {
  // 1. Basic structure
  if (!boleto.banco) throw new Error('Bank required');
  if (!boleto.banco.cedente) throw new Error('Beneficiary required');
  if (!boleto.banco.cedente.contaBancaria) throw new Error('Bank account required');
  if (!boleto.sacado) throw new Error('Payer required');

  // 2. Dates
  if (boleto.dataProcessamento === null) {
    boleto.dataProcessamento = new Date();
  }
  if (boleto.dataEmissao === null) {
    boleto.dataEmissao = new Date();
  }

  // 3. Aceite
  if (boleto.aceite !== 'A' && boleto.aceite !== 'N') {
    throw new Error('Aceite must be A or N');
  }

  // 4. Bank-specific validations
  boleto.banco.validateBoleto(boleto);

  // 5. Format Nosso Número
  boleto.banco.formataNossoNumero(boleto);

  // 6. Generate barcode
  generateBarcode(boleto);

  // 7. Generate digitável line
  generateDigitavelLine(boleto);
}
```

## Summary Checklist

Before generating a boleto, ensure:

- [ ] Bank code and beneficiary configured
- [ ] Payer information complete (name, CPF/CNPJ, address if required)
- [ ] Due date within acceptable range (±8/15 years from today)
- [ ] Amount greater than zero and within limits
- [ ] Nosso Número provided and within bank's max length
- [ ] Document species valid for the bank
- [ ] Aceite is 'A' or 'N'
- [ ] Carteira implemented for the bank
- [ ] Issue/processing dates valid (default to today if empty)
- [ ] Interest, fine, discount rules configured correctly
- [ ] Protest/return instructions valid
